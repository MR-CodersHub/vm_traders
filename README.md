# VM Traders Static E-commerce Site

This project is a fully frontend e-commerce demo built with HTML, CSS, and JavaScript.

All data is stored locally using browser `localStorage`, and no PHP, Python, or server-side API calls are required.

## Run Locally

1. Open the project folder in VS Code.
2. Install the Live Server extension (optional).
3. Open `index.html` with Live Server or any static file server.
4. The site will work offline and independently with local browser storage.

## Features

- Product browsing and filtering
- Cart and wishlist management
- User signup/login using localStorage
- Order checkout and order history stored locally
- Admin pages powered entirely by local data

## Notes

- External backend services and server endpoints have been removed.
- The project supports standard HTML navigation with relative links.
